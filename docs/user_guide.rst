User guide
==========

Cassiopeia is a flexible tool for analyzing lineage-tracing data and benchmarking new algorithms. Perhaps the easiest way to get started with Cassiopeia is by following along with our tutorials. Generally, we'll expect that you've already successfully installed Cassiopeia using the :doc:`installation guide<installation>`.

Cassiopeia stores data in `TreeData <https://treedata.readthedocs.io/en/latest/>`_ objects, and the tutorials use `pycea <https://pycea.readthedocs.io/en/latest/>`_ to plot and analyze trees.

For any questions about Cassiopeia, please file an issue on `Github <https://github.com/YosefLab/Cassiopeia/issues>`_. If you'd like to contribute a tutorial or a new algorithm, please follow our :doc:`Contributing guide<contributing>`.
